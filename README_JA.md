# Nitoryu: 二刀流戦闘システム

*English: `README.md`. Русская версия: `README_RU.md`. 中文: `README_ZH.md`.*

*この日本語の説明は機械翻訳です（ゲーム内の日本語テキストも同じく）。おかしいところがあれば、Workshop の討論ページで教えてください。*

みなさんこんにちは！これは Kenshi で二本の刀で戦うための mod です。刀を二本持った剣士は両方を抜き、片手に一本ずつ持って戦います。主の手はいつも通り振り、二の太刀が自分の攻撃、双撃、受け、いくつかの特殊技を加えます。

自分でもこの mod でずっと遊んでいます。環境は Second Life of Kenshi + その上に 200 mod。自分はアニメーターではないので、アニメーションはお手柔らかに。今は自作のアニメーションが 50 以上あり（攻撃、受け、受けに当たったときの反応、走り、抜刀と納刀、段位ごとの構え、スキルと一緒に開く技）、1.1.0 でその大部分を作り直したので、ようやくちゃんとした剣さばきに見えるようになりました。完璧にはまだ遠いですが、前より一段上です。

最初は一刀より弱いです。レベルが上がると新しい攻撃、受け、技が開き、能力値 80 前後では、二刀使いは同じ能力の一刀の相手より 25-30% 強く、複数の敵を相手にできます。

mod は普通に遊べますが、作業は続いています：技もアニメーションも増やし、上の段位も調整していきます。デフォルトでは二刀使いは私の技だけを使うので、他のアニメーション mod が二刀に混ざりません（「他の mod のアニメーション」参照）。バグの送り方は最後にあります。

## 必要なもの

- **RE_Kenshi 0.3.5 以降**（KenshiLib 0.5.0 付き）：[Nexus](https://www.nexusmods.com/kenshi/mods/847) または [GitHub](https://github.com/BFrizzleFoShizzle/RE_Kenshi)。
- **Kenshi 1.0.65**（Steam 版で確認、GOG でも動くはず）。他のバージョンでは二刀の構えはオフのまま（ログに一行出ます）、左手での戦闘は動きます。
- DualWieldProbe と一緒に使わないでください：どちらも同じ戦闘コードを変えます。Nitoryu はもう自分をオフにせず、ログに一行残すだけなので、戦闘で何が起きても自己責任です。
- **[Mod Config Menu](https://steamcommunity.com/sharedfiles/filedetails/?id=3813761584)** は任意ですが、強くおすすめします：設定を全部ゲーム内で切り替えられます。

## インストール

1. Steam Workshop でサブスクライブ（または `Nitoryu` フォルダを `Kenshi\mods\` に置く）。
2. **Nitoryu** を有効にして、ロード順の一番最後、メインの mod 全部の後に置いてください。`RE_Kenshi_log.txt` に別のプラグインが Nitoryu の上で何かをフックしていると出たら、Nitoryu をその mod の下に移してください：一部のプラグイン（たとえば KEP の近接 XP 修正）はゲームの関数を置き換えて先に渡さないので、二刀流が上がらなくなります。
3. いつも通り RE_Kenshi からゲームを起動。

外すときは無効にするだけです。セーブは読み込めて、キャラクターは二刀流の数値だけを失います（mod をまた有効にすれば戻ります）。`Kenshi\mods\` に Nitoryu のテスト版がまだ残っていたら、そのフォルダは削除してください：動くのは一つだけです。

## 使い方

- キャラクターの**背中に武器を二本**（または背中に一本、腰に一本）装備して抜刀します。抜いた方が右手、もう一本が左手に行きます。スロットを丸ごと使う武器も組み合わせに使えます。
- **刀とサーベル**が二刀にできます。刀一本とサーベル一本でも大丈夫です。鈍器とハッカーはオンにできます（`[Weapons] categories=0,1,2,4`）が、テストしていませんし、専用の技もありません。重武器、長柄武器、弓は二刀にできません。左手用のモデル（`bare sword`）がない武器は二の太刀になれず、その組み合わせは一本で戦います。
- インベントリの背中の武器スロットにある**ボタン**（交差した刀 = オン、灰色の刀一本 = オフ）で、そのキャラクターの二刀の構えをオン・オフします。選択は保存されます。デフォルトではホットキーなし、`[UI] hotkey=alt+n` で追加できます。
- その隣の**二つ目のボタン**（刀と棍棒が交差）は、鈍器かハッカーを二本、またはそのどちらかと刀かサーベルを持ったキャラクターに出ます。押せばそのキャラクターはそれらを二刀として使います。ini の編集は不要です。キャラクターと一緒に保存されます。`categories` と同じく、テストしていませんし、専用の技もありません。`[UI] any_weapon_button=0` で非表示にできます。
- どちらのボタンもマウスを乗せると説明が出ます。鈍器とハッカー以外は対応しません：重武器、長柄武器、弓は両手持ちです。`[UI] button_tips=0` で説明をオフにできます。
- それ以外は戦闘中に自動で進みます：剣士は自分の段位に合わせて攻撃、受け、技を選びます。
- **ゲーム内の設定：** [Mod Config Menu](https://steamcommunity.com/sharedfiles/filedetails/?id=3813761584) を入れると、ゲームのオプション画面に MCM タブができ、Nitoryu のページが二つあります：「Nitoryu」（Nitoryu の技のみ、走り方、私のアニメーション一つずつ、インベントリのボタン、二刀で戦う NPC、速度の上限、左腕の見た目）と「Nitoryu: extra」（マークとステータス画面の行）。各行にヒント付きで、英語、ロシア語、中国語、日本語に対応。変更は `Nitoryu.ini` に書き込まれます。メニュー mod がなくても何も変わらず、ini は今まで通り使えます。
- **頭上のマーク**は段位のスキルが働いていることを文字なしで示します：減っていくバー付きの波は流水、輪は双撃を待っている無限の連鎖、敵の上のひし形は圧迫の重ね数（最大で赤）。選択中のキャラクターに表示されます。各マークの意味と効果は、ステータス画面の二刀流の説明、道の計算式の横にあります。`[Marks] marks=2` で自分のキャラクター全員に表示、`marks=0` でオフ。

## スキル：二刀流と道

**二刀流**は、全キャラクターのステータス画面（武器の列）に追加される新しいスキルです。

- 他のスキルと同じく戦うだけで上がりますが、二刀か左手で戦ったときだけです：そうした一撃ごとの武器 XP の半分がこちらにも入ります。武器スキルより低いうちは早く、上回ると遅く上がります。
- 新しいキャラクターは、刀かサーベルの一番高いスキルの四分の一から始まります。
- 最初のレベルは**二刀用訓練人形**で鍛えられます（後述）。
- 戦闘中は防具と過積載で下がります。二刀流は身軽な剣士がコンセプトなので：重装甲一つにつき 7%、中装甲一つにつき 4%（軽装甲と服は 0）。下がった分はスキルの横に赤で表示され、マウスを乗せると理由と量が出ます。
- セーブと一緒に保存されます。

**道**は二刀での総合的な腕前で、0 から 100 の数値です。五つから計算されます：二刀流（60%）、二つの武器スキルの低い方（10%）、器用さ（10%）、近接攻撃（10%）、近接防御（10%）。全部 X なら道も X。能力値は戦闘中の実際の値で数えるので、負傷、防具、過積載で道が下がり、戦闘の途中で段位が落ちることもあります。

## 段位

道は五つの段位を開きます。3-5 段は二刀流そのものも必要です。

| 段位 | 道 | 二刀流 | 内容 |
|---|---|---|---|
| 1 弟子 | 20 | - | 二の太刀が自分で攻撃を始める、左右それぞれ私のアニメーション付きの最初の攻撃、大斬り |
| 2 武士 | 40 | - | 主の刀が受け損ねた攻撃を二の太刀が受ける。左手の斬り下ろし |
| 3 浪人 | 60 | 40 | 双撃、受けからの返し技、圧迫、二本で同じ部位、背面受け、特殊技（十字斬り、踏み込み斬り）、他の mod の長い技を二刀で |
| 4 剣士 | 75 | 60 | 流水、旋風斬り、二人同時の相手 |
| 5 剣聖 | 90 | 80 | 無限：二刀の技がずっと早く戻り、当たった双撃から次の双撃につながる |

段位ごとに自分の構えもあります（アニメーション参照）。1 段未満の剣士は刀を二本持っているだけで、初心者のペナルティを受けます。

### 1 段、弟子（道 20）

- **二の太刀の攻撃。** 左の刀が自分で攻撃します：左手の斬り、**左手の逆斬り**、**左手の胴斬り**、**左手の袈裟斬り**、**左手の斬り上げ**（全部自作のアニメーション、その場から）。
- **主の手の攻撃。** 右の刀にも専用の攻撃があります：**右手の斬り下ろし**、**右手の水平斬り**、**右手の逆斬り**。
- **大斬り。** 届かない敵用の攻撃：三歩踏み込んで、右の刀を首から腰へ斜めに振り下ろします。
- 二の太刀の頻度：道 20 で攻撃の 20%、40 で 23%、60 で 26%、75 で 30%、85 で 40%、90 で 50%、100 で 55%。大斬りは 7 秒に一回まで。その間、届かない剣士は歩いて近づきます。
- 二の太刀の攻撃は二本目の武器自身のダメージ、出血、装甲貫通を使い、道 20 で x1.04、40 で x1.14、70 から x1.30。

### 2 段、武士（道 40）

- **二の太刀の受け。** 主の刀が受け損ねた攻撃を二の太刀が受けます：二人目の敵の攻撃（満額の確率）、または同じ敵の連撃の後の攻撃（半分）。
- 確率：道 40 で 20%、60 で 30%、75 で 40%、90 で 50%、100 で 55%。
- 正面と側面（左右 110 度）だけで、剣士が振っている間、よろめいている間、倒れている間は受けません。ゲーム内の一秒に一回まで。
- 浪人（3 段）からは、背後からの攻撃も半分の確率で受けようとします：背面受け。
- 新しい攻撃：**左手の斬り下ろし**、そして自作アニメーション付きの五つ：**二刀の斬り下ろし**、**脚斬り**、**二刀開き斬り**、左右それぞれの**胸への横斬り**。さらに**二刀の胴斬り**：一歩踏み込み、二本が両側から水平に入り、左が腹、右が胸を斬ります。

### 3 段、浪人（道 60、二刀流 40）

- **双撃。** 一振りで二本、同時に二つの傷：二刀打ち下ろし、十字払い、**二刀の薙ぎ**（自作アニメーション）。道 60 で二の太刀の攻撃の 25%、100 で 45%。自作アニメーション付きの双撃がさらに三つ：**一、二**、**二刀の鋏**、**八の字斬り**、そして届かない敵用の**二歩斬り**（歩きながらの一、二）。新しい二の太刀の攻撃もあります：左手の連撃。
- **返し技。** 受けた後 1.5 秒以内の次の攻撃が、二の太刀か二本での返し技になることがあります：道 60 で 30%、100 で 60%。
- **一騎打ちでの受け。** 向き合っている敵の最初の一撃も、半分の確率で二の太刀が受けるようになります。
- **圧迫。** 敵があなたの攻撃を受けるたびに、その敵に圧迫が一つ重なります（最大 5、3 秒ごとに一つ消える）。重なるたびに、ゲームが次に誰が振るかを決めるときに不利になるので、敵は受けが増えて攻撃が減ります。敵の攻撃が当たると消えます。
- **同じ部位。** 双撃の二本が同じ敵に当たったとき、二本目は一本目が当たった部位を狙います：道 60 で 80%、75 から必ず。手足が早く落ちます。
- **特殊技**（二刀流 50 も必要）：
  - **十字斬り**（旧名：十字の止め）：右の刀を振り下ろし、次に左、X の形。よろめいている敵、圧迫が最大（5）の敵、または四回に一回、受けや受け流しの後 1.5 秒以内に出ます。3 秒に一回まで。
  - **踏み込み斬り：** 最大 35 離れたところから突進し、刀を X に交差させ、当たる瞬間に開きます。剣士ごとに 12 秒に一回まで。
- **他の mod の長い技**（More Combat Animations の issen など）は二刀で打たれ、二の太刀も当たります。踏み込み斬りと 12 秒のクールダウンを共有します。`[Main] only_my_strikes=0` のときだけ：デフォルトでは二刀使いは私の技だけを使います。
- 二本で当たる技（双撃、十字斬り、踏み込み斬り）は **5 秒のクールダウン**を共有するので、二撃が連続しません。その間は二の太刀が一本で攻撃します。同じ技を二回続けて使うこともありません。
- 初心者の割れた守りはこの段位でなくなります。

### 4 段、剣士（道 75、二刀流 60）

- **流水。** 5 秒以内に剣士を狙った敵の攻撃が 3 回（受け、受け流し、被弾、どれも数える）あると、4 秒間集中します：器用さが斬撃ダメージでさらに +12%、攻撃速度 x1.04、その上限が 1.5 から 1.8 へ。その後 5 秒は攻撃を数えません。ダウンすると終わります。
- 双撃がさらに二つ：**頭回し斬り**と**三連斬り**。
- **旋風斬り。** 突進、二刀の薙ぎ、横への一歩、頭上の X へと上がる回転、そして十字に開く斬り：薙ぎと開きでそれぞれ二本が当たり、一つの技で 4 ヒット。離れた位置から（間合いの外 6-25）、20 秒に一回まで。旋風斬りが使える間は踏み込み斬りより先に出ます。
- **二人の敵に二本の刀。** 直近 8 秒以内にあなたを攻撃した二人目の敵が側面にいると、双撃か十字斬りの左の刀がそちらに当たり、右の刀は目の前の相手に残ります。

### 5 段、剣聖（道 90、二刀流 80）

- **無限**。二本で当たる技の 5 秒のクールダウンが、道 90 で 3.5 秒、道 100 で 2 秒まで縮みます。
- 当たった双撃は、クールダウンに関係なくすぐ次の双撃を引き出せます：道 90 で 25%、100 で 50%。つながった双撃からさらにつながることもあります。

## 最初はきつい

3 段未満では二刀は一刀より劣ります。道が上がるにつれて全部消えます：

- **ぎこちなさ：** 道 0 で近接攻撃と防御が -10、道 40 で消えます。
- **割れた守り：** 0-1 段で受けが弱く、2 段で半分、3 段からなし。
- **速度：** 道 0 で攻撃と受けの速度 x0.85、道 30 から通常。
- **筋力：** 二本は両方の武器の重さの 1.25 倍として数えるので、同じ刀二本には一本の 2.5 倍の筋力が必要です。
- **防具と過積載**は戦闘中の二刀流を下げ（重装甲一つ -7%、中装甲 -4%）、それに伴って道と段位も下がります。

## 何を組むか

- **二本目の武器のボーナス**は半分で数えます：攻撃、防御、屋内のボーナス。二本目自身の攻撃は、自分のダメージ、出血、装甲貫通、種族へのボーナスを使います。
- **長 + 短**（短い方が長い方の 80% 以下、刀 + 脇差など）：二の太刀の受けの確率 x1.30。
- **同じ長さ**（差が 10% 以内）：双撃 x1.30。
- **二種類**（刀 + サーベル）：二本目の防御ボーナスを満額で数えます。
- **二の太刀の XP：** 二の太刀の命中と受けは二本目の武器のスキルを鍛えます。

二刀流にマウスを乗せると、どの組み合わせを持っていて何が付くかが見られます。

## 攻撃速度：仕組みと確認場所

Nitoryu はゲームの速度の計算式を置き換えません。ゲームはいつも通り攻撃と受けの速度を計算し（器用さ、武器スキル、武器の重さと筋力、防具、攻撃速度は 1.2 まで）、Nitoryu はそれに**二刀の速度係数**を掛けます：

- 初心者は遅い：道 0 で x0.85、道 30 で x1。
- 達人は速い：器用さ 100 と道 100 で最大 x1.3。両方そろって初めて大きなボーナスになります（器用さ 60 + 道 60 で約 x1.06、器用さ 100 + 道 60 で約 x1.13）。
- 器用さは負傷と防具を含めた戦闘中の値で数えます。
- 二刀の攻撃速度の上限は 1.5（ゲーム自体は 1.2）、受けは 4.0 ですが、そこまで鍛える必要があります。流水中の上限は 1.8。
- 二刀使いの器用さは**戦闘中 +12%** として、斬撃ダメージと速度の計算に入ります。どの段位でも。

## ゲーム内で確認できる場所

ステータス画面で**二刀流**にマウスを乗せると：

- 「戦闘中の値」：今効いている二刀流の値。過積載や防具の影響があれば「-過積載」「-防具」とその係数。
- 「道：浪人 (62)」：段位と道、次の段位にまだ必要なもの、たとえば「浪人には二刀流 40」。
- 「段位」：五つ全部と、それぞれで開くもの。到達したものはゲームのアイテム等級の色（色変更 mod も反映されます）、それ以外は灰色で条件付き。
- 「二刀の速度ボーナス：x1.04」：攻撃と受けの速度にかかる Nitoryu 独自の係数。
- 「戦闘中の器用さ：+12%」。
- 「組み合わせ」：あなたの組み合わせで付くもの。

戦闘中に武器を抜いた状態で**器用さ**にマウスを乗せると、「攻撃速度」と「受け速度」に最終的な数値が出ます。

キャラクターが新しい段位に達すると、段位の名前を言い、ゲームのメッセージが出ます。

## 二刀用訓練人形

mkI、mkII、mkIII の三つの建物で、二刀流をそれぞれ 10 / 20 / 30 まで鍛えられます。それぞれに研究があります（Pair Training Dummies、Better、Advanced。訓練カテゴリ）。キャラクターは武器スロットに片手刀を二本持っている必要があり、抜かなくても構いません。3 段以上は戦闘で上げるしかありません。

## 左手での戦闘

バニラでは右腕が使えなくなったキャラクターは素手格闘になります。二刀流 50 以上で左腕が無事なら、片手の刀かサーベルを**左手**で持って戦い続けます。右腕を失っていても同じです。武器一本でも二本でも動きます（そのときは一本を使います）。

- 二刀流 50 で：ダメージ 70%、攻撃と受けの速度 85%、受けるときの防御 -10。100 でペナルティはなくなります。
- 技はすべて鏡写しで、使えない腕は垂れ下がって体の動きに合わせて揺れます（`[Animations] limp_arm_swing=0` で動かなくなります）。
- 二刀流を鍛えます。

## NPC

- 許可された組み合わせを持った NPC は、器用さ 30、両方の武器スキル 30、二本の重さの半分以上の筋力があれば二刀で戦います（`[NPC] dual=all`）。
- NPC は 3 段より上には行きません（`[NPC] max_tier`）。
- `[NPC] dual=authored` は他の mod が指定した NPC だけ、`off` は誰も。
- NPC の二刀流は一番高い武器スキルの四分の一から始まります。もっと上げたいときは ini に `[NPC] skill=<string id>:<value>`：CHARACTER か FACTION 全体の id をカンマ区切りで。その値から始まり（セーブにすでにいるキャラクターもその値まで上がります）、そこから伸びます。

## 他の mod のアニメーション

- **デフォルトでは二刀使いは私の技だけを使います**（1.1.0）：バニラの振りや他の mod の技は二刀に混ざりません。間合いの外では、他の mod の長い突進ではなく歩いて近づきます。前の混ざった状態に戻すには：`[Main] only_my_strikes=0`、つまり `Nitoryu.ini` の一行目か、設定メニューの一行目。あなたのアニメーション mod は攻撃以外のところでは今まで通り見えます：歩き、ゲーム自身の受け、被弾の反応。
- 左腕は右腕をフレームごとに鏡写しにします（構え、歩き、走り、攻撃）。なので二刀の構えはあなたのアニメーション mod の雰囲気を引き継ぎます。
- 他の mod の長い技（攻撃距離 20 以上）は、特殊技を持つ剣士が二刀で打ちます。持っていない剣士は、両手で一つの柄を握る長い技を使わず、ゲームが別の技を選びます。
- 私のアニメーションはゲームのトラックの上で再生され、振り、受け、被弾があるとすぐに譲ります。剣士がよろめく、倒される、気絶する、起き上がるときは身を引き、ゲーム自身のアニメーションが再生されます（`[Animations] yield_to_reactions=0` で前のやり方に戻ります）。

## 私のアニメーション

すべて二刀用に作ったもので、`[Animations]` で一つずつオフにできます（オフにすると鏡写しのゲームのアニメーションになります）。

1. **二刀の抜刀：** 両手が頭の後ろの柄に上がり、二本を抜いて大きく左右に開き、構えに入ります。二本目が腰にあれば腰から。`dual_draw`。手が取るまで刀は背中のまま（`dual_draw_hold`、0 = 最初のフレームから手に）。
2. **二刀の納刀：** 体を鞘の方へかがめ、先に右、次に左の刀を戻します（ゲームが提げている背中か腰へ）。時間がかかるのは見た目だけで、ゲームはすぐに納刀するので、応急手当や運搬はバニラ通りすぐ始まります。`dual_sheathe`。
3. **血振り：** 勝った直後（敵が死んだ、倒れた、気絶した）に納刀する剣士は、まず二本を下と外へ振り、一拍置いてから納めます。`dual_chiburi`。剣士がそのまま応急手当、添え木、略奪、誰かを担ぐことに移るときは、血振りも納刀も再生されず、刀はそのまま戻ります（`sheathe_yields_to_jobs=0` で前のやり方に戻ります）。
4. **段位ごとの構え：** 戦闘中、攻撃も受けも走りもしていないとき、剣士は自分の段位の構えを取り、切り替わりません：弟子は一本を普通の構えで持ち、もう一本は腿の横で忘れられたまま。武士は鍛えられた構え。浪人は一本を腰の後ろに隠す。剣士はこめかみから水平な刀で狙う。剣聖は一本を肩に乗せる。1 段未満はゲームの構えです。敵に歩いて近づくときも腕は構えのまま。`idle_stances`。
5. **刀を持っての走り：** 四つの走り、`run_style`：3（デフォルト）右の刀を逆手で背中に沿わせ、左は右側へ。2 右の刀を後ろに引きずり、左は肩のそば。1 左腕を後ろに振り、その刀を低く引く。0 前の走り（二本を後ろに引き、ゲームの脚の動きに重ねる）。4 = 1 か 3、剣士ごとに一度だけ選ぶ。1-3 は深く前傾し、脚も含めて全身が動きます。`run_hold` で全部オフ。他の mod の走りの上では 0 に戻り、上半身はその走りに半分だけついていきます（`run_hold_free_weight`、0 から 1、デフォルト 0.5）。
6. **方向に合わせた主の手の受け：** 構えが攻撃についていきます。左か右からは二本一緒にその側へ傾け（**斜め受け**）、上からは右の刀を頭上に水平に（**上段受け**）、正面からは**鋏の X** か一刀の受け（右の刀を体の前に横に、左は腰に引く）をランダムで。`angled_block`、`main_block`、`scissor_block`、`main_block_single`。
7. **受けに当たったとき：** 攻撃が刀に当たると、構えが一度押し戻されて戻ります。X の受けは `dual_block`。
8. **通ってしまった攻撃：** 受けていないときに当たると、一度後ろにのけぞり、二本とも持ったまま。`hit_taken`。
9. **二の太刀の受け：** 左の刀だけの受け：前に横向きに上げ、体をひねって攻撃を肩の外へ流し、右の刀は腰に引きます。`offhand_block`。オフにすると左の刀を頭上に上げます（`high_block`）。
10. **二刀の薙ぎ**、**一、二**、**左手の逆斬り**、**二刀の斬り下ろし**、**脚斬り**、**二刀開き斬り**、**左手の胸斬り**、**右手の胸斬り**、**左手の胴斬り**、**右手の斬り下ろし**、**左手の袈裟斬り**、**右手の水平斬り**、**左手の斬り上げ**、**右手の逆斬り：** 専用のアニメーションを持つ十四の攻撃。`twin_sweep`、`one_two`、`off_backhand`、`double_chop`、`off_leg_cut`、`dual_cut`、`off_hand_cut`、`main_hand_cut`、`off_belly_cut`、`main_chop`、`off_shoulder_cut`、`main_level_cut`、`off_high_cut`、`main_short_cut`（0 = その技を使わない）。
11. **二刀の鋏**、**八の字斬り**（浪人）、**頭回し斬り**、**三連斬り**（剣士）：上の段位の四つの双撃。鋏は二本が逆方向に交差し、右が首、左が腿を斬ります。八の字斬りは各刀が一回転して止まらずにそれぞれの斜めへ。頭回し斬りは右の刀が頭の後ろを回り、長い突きで終わります。三連斬りはその場から：右の刀が左の腰から肋骨を斬り上げ、左がその下で鏡写しに上がり、右が肩から落ちます。`twin_shear`、`figure_eight`、`head_wrap`、`three_cuts`。
12. **大斬り**（弟子）、**二刀の胴斬り**（武士）、**二歩斬り**（浪人）：踏み込む三つの攻撃。大斬りは三歩踏み込んで右の刀を斜めに振り下ろす。胴斬りは一歩踏み込み、二本が両側から水平に入る。二歩斬りは歩きながらの一、二。大斬りと二歩斬りは届かない敵用。`big_chop`、`twin_body_cut`、`two_step`。
13. **十字斬り**（旧名：十字の止め）、**踏み込み斬り**、**旋風斬り：** 三つの特殊技の全身アニメーション。`x_cut`（古い `cross_finisher=` も有効）、`dash_slash`、`spin`。
14. **背面受け**（浪人以上）：振り向かずに背後からの攻撃を受け、刀を背中に渡します。低いのは腰の後ろ、高いのは肩の上。背後の敵を受け流すときは二の太刀、受けたときは主の刀。`back_guard`。

斜め受けが攻撃と逆の方へ傾く場合は、`[Animations] angled_block_swap=1` にしてください。

## mod 作者の方へ：FCS の中の Nitoryu

FCS での調整項目を求める声が多かったので、Nitoryu の大部分はデータです。C++ は不要で、Nitoryu の後に読み込む mod があれば十分です。

1. **バランス。** 約 100 の設定が GLOBAL CONSTANTS に `nitoryu ...` フィールドとしてあります：道の重み、段位、全ての曲線、ペナルティ、速度、受け、圧迫、流水、無限、組み合わせのボーナス、NPC のルール。あなたの mod でフィールドを変えれば、その mod を使う全員に効きます。プレイヤーが自分の `Nitoryu.ini` で同じものを設定していれば、そちらが優先です。
2. **技。** 二刀の技は、いくつかの `nitoryu` フィールドを持つ COMBAT_TECHNIQUE レコードです：何の技か（二の太刀の攻撃、双撃、止め、距離からの技）、クールダウン、距離、どのクリップを重ねるか。私の技もまさにこの方法で作っているので、一つコピーして変えてください。
3. **武器。** WEAPON の `nitoryu dual wield` で、カテゴリに関係なく組み合わせに入れるか外すかを決めます。`nitoryu off hand damage` で二の太刀としてのダメージ、`nitoryu pair length` で組み合わせでの役割（長いか短いか）を変えます。FCS Extended なしでは：WEAPON を「Nitoryu weapons allowed in a pair」か「Nitoryu weapons refused in a pair」の `weapons` リストに追加します（どの店も使わない商人リスト二つ）。プレイヤーは ini の `[Weapons] allow=` / `refuse=` で同じことができます。技の `nitoryu move weapons` で、その技がどの武器カテゴリ用かを決めます。
4. **NPC。** CHARACTER か FACTION で `nitoryu dual wielder` にチェックを入れると、組み合わせを持っているときに二刀で戦います。能力の下限も段位の上限もなく、プレイヤーが `[NPC] dual=authored` にしていても有効です。古いやり方も使えます：小隊「Nitoryu dual wielders (opt-in list)」（出現しません）に追加するか、ini に `[NPC] opt_in=<string id>,<string id>`。普通の FCS で二刀流スキル（ステータス画面の数値）を設定するには、キャラクターか勢力を小隊「Nitoryu dual wielders (Dual Wielding 40 / 60 / 80 / 100)」のどれかに追加するか、そこでキャラクターの一つ目の値に正確な数値を入れます。これで二刀の達人に能力を盛る必要がなくなります。フィールド `nitoryu dual wielding` と ini の `[NPC] skill=<string id>:<value>` も同じです。能力に関係なく達人でなければならない NPC には、最低の道も設定してください：それらの小隊でのキャラクターの二つ目の値、フィールド `nitoryu path`、または `[NPC] path=<string id>:<value>`。
5. **種族。** あなたのスケルトンで私の鏡写しがおかしく見えるときは、RACE に `nitoryu rig`：1 で二の太刀を左手の固定の握りにし、2 でその種族の Nitoryu をオフにします。
6. **訓練。** 訓練用の BUILDING に `nitoryu pair dummy` を付けると、その `output rate` まで二刀流を鍛えます。
7. **自作のプラグイン。** RE_Kenshi のプラグインを書くなら C++ API があります：キャラクターが二刀で戦っているか、段位、道、二刀流を問い合わせ、イベント（二の太刀の命中、受け、特殊技、段位の変化）を受け取り、自分の組み合わせのルール（どの二つの武器でも、重い武器も、自分の数値で）を追加できます。マニュアルはこのファイルの隣の `API.md`（ロシア語版：`API_RU.md`）、ヘッダは `NitoryuApi.h`、サンプルのアドオンはソースのリポジトリにあります。

フィールドをツールチップ付きで FCS に表示するには FCS Extended が必要です（mod フォルダの `fcs.def` を読み込み、Second Life of Kenshi 自身のフィールドと同じように表示されます）。プレイヤーには不要です。マニュアルはこのファイルの隣の `FCS.md`（技の追加方法、全フィールド、私のレコード、普通の FCS での NPC の二刀流の設定方法。ロシア語版：`FCS_RU.md`）、設定の表は `FCS-settings.md`、全フィールドと説明は `fcs.def` にあります。ゲームデータ上ではスキルはまだ Ambidexterity、道は「DP」という名前です。

まだできないことが一つあります：両腕を自分で動かし、作った通りに再生されるトラック。今のところ技は右手のトラックで、私がそれを鏡写しにするか二本に乗せています。

## 設定

mod フォルダの `Nitoryu.ini` で、ゲーム起動時に読み込まれます（設定メニューもここに書き込みます。「使い方」参照）。短いです：上にスイッチ、下にデフォルト値付きのバランスのキー。バランスのキーはコメントアウト（`;` 付き）で配布しています。ゲームデータにもあって mod が変えられるからです。`;` を外せばあなたの値が優先されます。よく使いそうなもの：

- `[Main] only_my_strikes`（1）：二刀使いは私の技だけを使う。0 でゲームの振りと他の mod の技を混ぜます。
- `[General] language`：`auto`、`en`、`ru`、`zh`、`ja` など（中国語のテキストは Workshop の討論ページの 7 さんによるものです、ありがとう！日本語は機械翻訳なので、修正歓迎です）
- `[General] diag`：`RE_Kenshi_log.txt` にどれだけ書くか：`off`、`normal`（デフォルト）、`stage`、`verbose`。
- `[UI] toggle_button`、`any_weapon_button`、`button_tips`、`button_size`、`hotkey`。
- `[Stats] rank_colours`、`rank_up_message`、`rank_in_title`（ステータス画面のタイトルの段位、デフォルトでオフ）、`panel_pair_bonus`（二刀を抜いている間、キャラクターパネルの攻撃と防御に二の太刀を含める）、`group`（二刀流の行の位置：1 武器 / 2 戦闘）。
- `[Marks] marks`（0 / 1 選択中 / 2 自分のキャラ / 3 全員）、`place`（2 頭上 / 1 ポートレート / 3 両方）、`flow`、`mugen`、`pressure`、`tips`、`size`、`height`。
- `[Animations]`：私のアニメーションそれぞれのオン・オフ、そして `run_style`（どの走りか、上記）。
- `[NPC] dual`（`all` / `authored` / `off`）、`max_tier`、`opt_in`、`skill`。
- `[Weapons] categories`：何を組み合わせにできるか。
- `[Guard] cooldown_ms`（ゲーム内の一秒に一回の受け）、`arc_deg`（110 = 正面と側面）、`back_min_tier`（3：背中を守り始める段位、6 = なし）、`back_share`（そこでの受けの確率の 0.5）。
- `[Moves] dash_cooldown_ms`（12000）、`spin_cooldown_ms`（20000）、`double_hit_cooldown_ms`（5000）、`no_repeat`、`even_picks`（1：出てきた技のうち、二の太刀が一番使っていないものを選ぶ）、`cross_riposte_chance`（0.25：十字斬りが受けに応じる頻度）、`big_chop_cooldown_ms`（7000）、`main_move_share`（0.6：二の太刀が取らない攻撃のうち、私のアニメーション付きの右の刀の攻撃の割合）。
- `[Speed] dual_speed_bonus`、`dual_attack_cap`。
- `[Flow]`、`[Mugen]`、`[Pair]`、`[Scissor]`（同じ部位）、`[Split]`（二人の敵）、`[Training]`、`[LeftHand]`：各仕組みのスイッチと数値。
- `[Balance]`：道による全ての曲線。

## プラグイン作者の方へ：Nitoryu がフックするもの

プラグイン用の C++ API は `API.md` にあります。あなたのプラグインもこれらのどれかをフックしている場合、両方が動きます（フックはつながります）が、何か壊れたら教えてください。起動時に Nitoryu は、先に誰かがフックした対象ごとに `shared_hook target=...` を、プレイ 60 秒後に `compat` の行をログに書きます。

- `Character::hitByMeleeAttack`（二の太刀のダメージ、崩れた守り）、`Character::~Character`（後片付け）
